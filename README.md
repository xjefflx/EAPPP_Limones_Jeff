# Gestor Rápido de Pedidos - Cafetería Universitaria

Aplicación de escritorio desarrollada en C# (Windows Forms) para gestionar pedidos de una cafetería universitaria a partir de un catálogo predefinido, calculando subtotales y totales en tiempo real con opciones de entrega y extras[cite: 1, 2, 3].
